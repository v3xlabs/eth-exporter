# eth-exporter

a rust crate for fetching ethereum prices & exchange rates via Ethereum RPC.

## Supported Quoters

- Uniswap V2
- Uniswap V3
- ERC4626
  - Morpho Vaults
  - Aave v3 Earn Vaults
- Fixed

## Features

- BYO Ethereum RPC Provider
- Quoter discovery between pairs
- Fetch rates for quoters by block number
- Quoter route calculation
